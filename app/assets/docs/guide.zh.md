# 使用指南

本指南介绍秋云 M3U8 下载器的完整使用方法、HLS 格式知识以及常见问题的排查方式。

## 快速上手

### 方式一：油猴脚本（推荐）

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展；
2. 安装[秋云 M3U8 下载助手](https://update.greasyfork.org/scripts/603547/%E7%A7%8B%E4%BA%91%20M3U8%20%E4%B8%8B%E8%BD%BD%E5%8A%A9%E6%89%8B.user.js)脚本；
3. 打开包含视频的网页，页面右侧会出现深色悬浮按钮，脚本自动嗅探页面中的 m3u8 链接；
4. 点击悬浮按钮，确认视频标题与封面后一键跳转到下载页，链接自动填好；
5. 选择保存目录（可选），点击「开始下载」。

### 方式二：手动粘贴链接

如果你已经拿到 m3u8 地址，直接打开[下载页](/)，粘贴到输入框即可，无需安装任何扩展。

## 功能详解

### 下载模式：流式 vs 内存

| 模式 | 原理 | 适用场景 |
|---|---|---|
| 流式下载（默认开启） | 每个分片下载完成后立即写入磁盘，内存占用恒定 | 大文件、长视频、配置较低的电脑 |
| 内存模式 | 全部分片缓存在内存中，最后一次性合并 | 小文件、不想授权目录访问权限 |

流式下载需要通过浏览器的 File System Access API 选择保存目录，仅 Chrome / Edge 等基于 Chromium 的浏览器支持。若取消目录选择，本次下载会直接终止而不是静默改为浏览器下载。

### 并发控制

默认并发 6 个分片请求，与浏览器对同一域名的连接数上限一致，无需调大——调大只会增加内存开销，不会加快速度。网络较差时可降低并发减轻服务器压力。

### TS 转 MP4

开启「转 MP4」后，TS 分片会被无损转封装为 MP4：

- **不重新编码**，无画质损失，速度接近直接下载；
- 仅支持 H.264 / AAC 编码，其他编码会自动回退保存原始 TS 文件；
- fMP4（分片 MP4）格式的流会自动识别，初始化片段（`#EXT-X-MAP`）会被正确下载并前置到合并文件中，保证播放器能识别时长与轨道信息。

### 加密视频（AES-128）

下载器完整支持 `#EXT-X-KEY:METHOD=AES-128` 加密：

- 自动识别播放列表中的密钥地址并下载解密；
- 支持全局密钥与分片级密钥（每个分片使用不同 KEY 标签的情况）；
- 显式 IV 与隐式 IV（由分片序号推导）均已处理。

### 暂停与取消

每个下载任务可以随时暂停（已发出的请求会等待完成，不再发出新请求）或取消（立即中止所有在途请求）。删除进行中的任务会同时终止后台下载并复位按钮状态。

## HLS / M3U8 格式科普

### m3u8 是什么

M3U8 是 HLS（HTTP Live Streaming）使用的播放列表文件，本质是一个纯文本文件，记录视频被切分后每个分片（通常 2~10 秒）的地址与时长。播放器按顺序下载分片即可实现边下边播。许多在线课程、直播回放、海外视频平台都采用这种格式分发视频。

### 主播放列表与多画质

如果一个 m3u8 文件里包含 `#EXT-X-STREAM-INF` 标签，说明它是「主播放列表」（Master Playlist），内部列出了多种分辨率/码率的子播放列表。下载器会列出全部画质供你选择，并显示带宽与分辨率信息。

### TS 与 fMP4

HLS 的分片有两种封装：

- **MPEG-TS**：传统格式，兼容性最好；
- **fMP4（分片 MP4）**：新一代格式，体积更小，Netflix、B 站等已逐步采用。

下载器通过 URL 后缀和文件头字节自动判断格式，选择正确的封装与 MIME 类型，fMP4 的初始化片段也会被正确处理。

## 故障排查

### 提示跨域（CORS）失败

浏览器安全策略禁止网页读取其他域名的响应。解决方式按优先级：

1. 安装油猴脚本，从目标网页内发起嗅探与下载（脚本具有跨域请求权限）；
2. 确认 m3u8 链接是否有时效性（部分 CDN 链接几分钟内失效，重新刷新页面获取新链接）；
3. 换网络环境再试——部分链接有地区或 IP 防盗链限制。

### 进度卡住不动

所有请求均有 60 秒超时保护，超时后自动重试。若整体进度长时间无变化，通常是源站限速或链接已失效，可暂停后重新开始，或刷新页面获取新链接。

### 下载完成的视频无法播放

- 用最新版 Chrome/Edge/VLC 打开；
- 确认下载时任务显示「完成」而不是「错误」——本项目绝不合并残缺分片，若中途有分片失败会明确报错；
- 若是 fMP4 流，请确认使用的是最新版本下载器（旧版本不支持 `#EXT-X-MAP`）。

### 部分分片下载失败

下载器会在主队列完成后自动追加最多 2 轮重试波次。若仍失败，任务会标记为错误并列出失败分片编号，此时应更换网络或稍后重试，而不是反复点击开始。
